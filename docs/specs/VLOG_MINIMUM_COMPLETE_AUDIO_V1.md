# Vlog Minimum Complete Audio v1

Status: FROZEN FOR IMPLEMENTATION
Branch: `feat/narration-segments-v1`

## Goal

スマートフォンだけで素材追加から音声確認、危険発言の伏せ、書き出しまで完結させる。
高機能な編集ソフトにはせず、一本のVlogを安全に成立させるための最小完結版とする。

## 1. Material input

- インカメ撮影
- アウトカメ撮影
- 端末ファイルから動画または画像を選択
- 元素材は削除・上書きせず保持する

## 2. Whole-asset post narration

### Video

- 後入れ音声を選んだ場合、元動画音声は全区間ミュートする
- 元動画の秒数を録音前に表示する
- 録音中は動画尺を逆算表示する
- 0秒を過ぎても録音を自動停止しない
- 録音後に超過または不足秒数を表示する
- 超過音声は書き出し用コピーの末尾をカットする
- 不足時間は書き出し用コピーへ無音を補う
- 元録音は保持する

### Image

- 録音前に画像表示秒数を設定する
- 録音中は設定秒数を逆算表示する
- 0秒を過ぎても録音を自動停止しない
- 録音後に超過または不足秒数を表示する
- 次のいずれかを選べる
  - 画像表示時間を録音時間へ合わせる
  - 設定した表示時間を維持し、超過をカットまたは不足を無音補完する

## 3. Audio confirmation

最低限、次を個別に確認できること。

- 元音声
- 後入れ音声
- 映像と後入れ音声の同期再生
- BGM使用時の最終MIX

確認前に書き出しを強制しない。

## 4. Optional BGM and one-slider MIX

- BGMは任意
- BGM未登録時は主音声100%とし、MIXスライダーを無効化する
- BGM登録時のみ0〜100のスライダーを表示する
- スライダー値をBGM割合とする
  - 0 = 主音声100 / BGM 0
  - 20 = 主音声80 / BGM 20
  - 50 = 主音声50 / BGM 50
  - 100 = 主音声0 / BGM 100
- 複数スライダー、EQ、コンプレッサー、複数BGM、詳細ダッキングはv1対象外

## 5. Beep masking

- 素材ごとに開始秒と終了秒を指定する
- 指定区間はピー音100%とする
- 同区間の元音声、後入れ音声、BGMはすべて0%とする
- 前後に極短い内部フェードを入れ、クリックノイズを防ぐ
- ピー音区間は自動無音判定の対象にしない
- ピー音区間は追加、確認、位置変更、削除ができる

## 6. Boundary-only automatic jump cuts

### Detection

- 判定対象は選択中の主音声トラックのみ
  - 元音声モード: 元音声
  - 後入れモード: 後入れ音声
- BGMは判定から除外する
- 音量しきい値以下が0.1秒以上続いた場合を無音候補とする

### Scope

- 各素材の先頭と末尾だけを処理する
- 素材途中の沈黙、言い淀み、演出上の間は切らない
- 完全無音素材を0秒へ縮めない
- 元素材を変更しない

### Handles

- 前素材の最後の声から0.1秒を残す
- 次素材の最初の声まで0.1秒を残す
- 隣接素材間の意図的な無音は最大0.2秒とする

### Synchronization

境界カットを適用した場合、同じ秒数だけ次を同期更新する。

- 映像
- 主音声
- 字幕
- ピー音区間
- タイムライン開始位置
- 素材時間と全体時間

## 7. Final mixed-audio safety audit

### Purpose

- iPhoneで直接撮影・録音した素材だけなら異常な高周波音の発生可能性は低い
- 外部動画、外部録音、BGMを取り込む場合まで含め、公開前の安全確認として実行する
- 編集機能ではなく、聞き取りにくい大音量高周波や機器発振音を見落とさないための安全ゲートとする

### Detection target

- 元音声、後入れ音声、BGM、ピー音、MIX、境界カットを反映した完成動画の最終音声を検査する
- 15kHz以上の高音域を狭い周波数帯ごとに検査する
- 次をすべて満たす場合だけ候補として扱う
  - 狭帯域へ音量が集中している
  - 完成音声全体と比べて無視できない大きさである
  - 0.3秒以上連続している
  - 一時的なシンバル、子音、クリック音ではない

### v1 action

- 通常モードは警告と記録のみとし、完成動画を勝手に変更しない
- 検出時は周波数候補、開始秒、終了秒、持続時間、音量をレポートへ保存する
- 公開前に端末音量を下げて該当区間を確認する
- 厳格モードでは候補検出または検査失敗時に完成扱いを止められる
- 自動ノッチ補正は誤検知で正常なBGMを壊す可能性があるため、実サンプルで妥当性を確認するまでv1標準では行わない
- 元動画と完成動画は削除・上書きしない

## 8. Non-destructive rules

- 元動画、元画像、元録音を上書きしない
- 尺合わせ、ピー音、MIX、境界カットは出力用データとして保持する
- 高周波安全検査は解析レポートだけを追加し、音声を無断加工しない
- 通常削除はゴミ箱へ移動し、復元可能にする
- 永久削除は別操作とする
- 自動公開・自動アップロードは行わない

## 9. v1 implementation order

1. 素材保存
2. 動画・画像の尺連動後入れ録音
3. 単体音声と映像同期の確認
4. 境界のみ自動ジャンプカット
5. 任意BGMと1本スライダーMIX
6. ピー音区間
7. 全体MIX確認
8. 書き出し
9. 完成MIX高周波安全検査

## 10. Acceptance checks

- 動画後入れ時に元音声が残らない
- 録音は0秒後も継続できる
- 超過・不足が0.1秒単位で見える
- 画像時間を録音尺へ変更できる
- BGMなしで正常に完成する
- BGMありでスライダー比率が反映される
- ピー音区間では他音声が聞こえない
- 先頭・末尾の余分な無音だけが詰まる
- 素材途中の間は保持される
- 場面間に最大0.2秒の余白が残る
- 字幕とピー音位置が境界カット後も同期する
- 完成MIXに高確信の持続高周波候補があれば時間帯付きで警告される
- 高周波候補がない通常音声は加工されずPASSになる
- 検査失敗が成功として扱われない
- 元素材、元録音、元完成動画が保持される
