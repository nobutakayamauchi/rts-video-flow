# Vlog Manual Audio Redaction UI v1

Status: FROZEN FOR IMPLEMENTATION
Branch: `feat/narration-segments-v1`

## Goal

利用者が完成MIXまたは選択素材を聞き直し、不快・危険・公開不適切だと感じた区間を、iPhone上で片手操作により正確に指定して処理できるようにする。

自動検出の結果だけに依存せず、利用者自身の聴覚判断を最終センサーとして扱う。

## 1. End-to-end flow

1. 完成MIXまたは選択素材を低音量で再生する
2. 嫌な音がした間、`嫌な音を記録` ボタンを押す
3. 反応遅れ補正を含む仮範囲を作成する
4. 両端つまみ付き範囲スライダーで開始・終了を調整する
5. 選択範囲を前後ハンドル付きでループ確認する
6. `無音`、`P音`、`音量低下`、`区間削除`のいずれかを選ぶ
7. 必要なら区間中に表示する括弧付き説明文を追加する
8. 処理後の区間を再生確認する
9. 全体MIXを再生成し、音声安全検査を再実行する

すべて非破壊処理とし、元素材、元録音、処理前完成動画を保持する。

## 2. Press-to-mark capture

- 画面中央に、片手で押せる大きな `嫌な音を記録` ボタンを表示する
- `pointerdown` 時点を仮開始、`pointerup` 時点を仮終了とする
- 押している間は色、振動、経過秒数で記録中であることを示す
- 初期反応補正は開始を0.4秒前、終了を0.2秒後とする
- 0.3秒未満の短いタップは、タップ位置の前0.5秒・後0.5秒を仮範囲とする
- 0秒未満または素材終了後へはみ出さない
- 再生停止、着信、画面離脱、`pointercancel`時は未確定範囲として確認を求める

## 3. Dual-handle range slider

### 3.1 Required UI

仮範囲を作成した後、動画または音声プレイヤーの直下へ両端つまみ付きスライダーを表示する。

```text
00:12.3  |==== 選択範囲 ====|  00:14.8
           2.5秒
```

- 左つまみは開始秒を変更する
- 右つまみは終了秒を変更する
- 選択範囲中央をドラッグした場合は、長さを維持したまま範囲全体を移動する
- 再生位置を示すプレイヘッドと、選択範囲のつまみを視覚的に分離する
- ドラッグ中は現在の開始秒、終了秒、選択秒数を常時表示する
- 0.1秒単位でスナップする
- 30fps素材では最終適用時にフレーム境界へ丸める
- 開始と終了が逆転しないよう最小範囲0.1秒を維持する

### 3.2 Fine adjustment

スライダーに加えて次を残す。

```text
開始 00:12.3  [-0.5] [-0.1] [+0.1] [+0.5]
終了 00:14.8  [-0.5] [-0.1] [+0.1] [+0.5]
```

- 数値直接入力も可能にする
- 前後1秒を含むループ確認を基本とする
- `選択範囲のみ再生`も用意する
- 調整内容はプレビューへ即時反映する

## 4. One-tap treatment modes

範囲確定前に、処理方法を大きなボタンで選択する。

```text
[残す] [音量↓] [無音] [P] [区間削除]
```

### 4.1 Keep

- 音声と映像を変更しない
- 手動候補を問題なしとして承認する

### 4.2 Attenuate

- 映像尺は維持する
- 選択区間の主音声と必要に応じてBGMを指定dBだけ下げる
- 初期値は `-12 dB`
- 簡易スライダーで0〜-30 dBを調整できる

### 4.3 Mute

- 映像尺は維持する
- 選択区間の元音声、後入れ音声、BGMをすべて0にする
- クリックノイズ防止のため前後へ極短い内部フェードを入れる

### 4.4 P beep

- 映像尺は維持する
- 選択区間の元音声、後入れ音声、BGMをすべて0にする
- 同区間へP音を100%で配置する
- P音開始・終了へ極短い内部フェードを入れる
- P音区間は無音判定、境界ジャンプカット判定の対象から除外する
- `P`ボタン選択時は、区間ループ再生へP音を即時反映する

### 4.5 Delete interval

- 選択区間の映像と音声を同じ範囲で削除する
- 字幕、P音区間、手動候補、自動候補、後続タイムライン開始位置を同期更新する
- 区間削除中は括弧説明文を表示できない
- 元素材を変更せず、出力用編集命令として保存する

## 5. Optional parenthetical annotation

無音またはP音で処理した場合、何が起きていたかを視聴者へ示すため、選択区間だけ括弧付き説明文を表示できる。

### 5.1 Examples

```text
（子どもの泣き声）
（警報音）
（ガラスをこする音）
（咀嚼音をカットしています）
（発言を伏せています）
```

### 5.2 Rules

- 説明文は任意であり、空欄でも保存できる
- 自動検出ラベルがある場合は候補文として提案するが、利用者の確認なしに確定しない
- 自由入力で変更できる
- 画面表示は処理区間と同じ開始・終了を使用する
- 表示形式は原則として全角括弧 `（ ）` を用いる
- 通常字幕とは別の注釈トラックとして保持する
- 元字幕を上書きしない
- 伏せた発言の実際の単語や個人情報を、自動で注釈へ復元しない
- 発言内容を隠す場合の初期文は `（発言を伏せています）` とする
- 音響イベントの場合は `（子どもの泣き声）` 等の一般的な説明に留める
- 画面内で他字幕と重なる場合は、安全な別位置へ配置する

### 5.3 Treatment compatibility

- `無音`: 注釈表示可能
- `P音`: 注釈表示可能
- `音量低下`: 注釈表示可能
- `残す`: 必要なら注釈だけ追加可能
- `区間削除`: 削除中の表示先がないため注釈不可

## 6. Preview contract

処理確定前に最低限、次を確認できること。

- 元音の選択区間
- 処理後の選択区間
- 前後1秒を含む処理後ループ
- 注釈付き映像
- 全体MIX内での処理結果

確認再生の初期音量は低くする。危険音候補では音量を勝手に最大へ戻さない。

## 7. Data contract

一つの処理区間は最低限、次を保持する。

```json
{
  "id": "manual-redaction-001",
  "source": "manual",
  "startSeconds": 12.3,
  "endSeconds": 14.8,
  "action": "beep",
  "attenuationDb": null,
  "annotation": {
    "enabled": true,
    "text": "（警報音）",
    "style": "parenthetical"
  },
  "reactionCompensation": {
    "startLeadSeconds": 0.4,
    "endTailSeconds": 0.2
  },
  "createdAt": "ISO-8601",
  "updatedAt": "ISO-8601"
}
```

`action`は次のいずれかとする。

- `keep`
- `attenuate`
- `mute`
- `beep`
- `cut`

## 8. Multiple ranges and batch editing

- 複数区間を一覧表示する
- 一覧から区間をタップするとスライダー位置へ移動する
- 複数選択して、同じ処理を一括適用できる
- 一括P音、一括無音化、一括音量低下、一括区間削除を用意する
- 一括注釈は共通文を適用するか、各区間個別入力を選べる
- 一括区間削除は後ろの時刻から適用する
- 適用後は全区間の時刻を再計算する

## 9. Replace recommendation

- 手動候補が5件以上、または合計が素材の15%以上なら `差し替えも検討` を表示する
- 手動候補が10件以上、または合計が素材の30%以上なら `素材差し替えを推奨` を強く表示する
- 推奨は提案のみで、自動削除しない
- 素材を差し替える場合は旧素材を復元可能なゴミ箱へ移動する

## 10. Non-destructive and safety rules

- 元動画、元画像、元録音、処理前完成動画を上書きしない
- 処理は出力用編集命令として保持する
- 適用後も個別処理を解除、変更、やり直しできる
- P音や無音化を解除した場合は元音声へ復元できる
- 永久削除は別操作とする
- 自動公開、自動アップロードは行わない

## 11. Acceptance checks

- 再生中に押している間を仮範囲として記録できる
- 両端つまみ付きスライダーで開始・終了を0.1秒単位に調整できる
- 範囲全体を長さを変えずに移動できる
- 選択区間を繰り返し確認できる
- 無音とP音をワンタップで切り替えられる
- P音区間では元音声、後入れ音声、BGMが聞こえない
- 無音またはP音中に任意の括弧説明文を表示できる
- 注釈が通常字幕を破壊しない
- 伏せた実際の発言を注釈へ自動復元しない
- 区間削除時に映像、音声、字幕、後続タイムラインが同期する
- 処理を解除すると元音へ戻せる
- 複数区間を一括処理できる
- 候補が多い場合に素材差し替えが提案される
