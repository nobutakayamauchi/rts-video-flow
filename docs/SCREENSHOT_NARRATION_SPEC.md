# スクリーンショット解析・ナレーション機能 仕様

## 目的

スクリーンショットをVlogへ差し込む際に、画像をただ表示するのではなく、

1. 画像が何を示しているかを解析する
2. 解析結果を編集可能な説明文として表示する
3. ブラウザ上の録音ボタンからナレーションを吹き込む
4. ナレーションを文字起こしして字幕を生成する
5. ナレーションの長さに合わせて画像表示時間を決める

ところまでを、一つの操作画面で完結させる。

## 重要な設計判断

SSHターミナル上の対話コンソールだけでは、iPhoneのマイク録音ボタンや画像プレビューを扱いにくい。

そのため、既存のCLIコンソールは残しつつ、追加機能は **スマホ向けWebコンソール** として実装する。

- CLI: 素材整理、バッチ処理、レンダリング、再実行
- Webコンソール: 画像確認、説明編集、録音、再生、順番変更

## 画面構成

各スクリーンショットを1枚のカードとして表示する。

```text
┌─────────────────────────────────────────────┐
│ スクリーンショット                           │
│ ┌─────────────────────┐ ┌─────────────────┐ │
│ │                     │ │ AIによる説明     │ │
│ │      画像プレビュー │ │ [編集可能]       │ │
│ │                     │ │                 │ │
│ └─────────────────────┘ └─────────────────┘ │
│                                             │
│ [● 録音開始] [■ 停止] [▶ 再生] [録り直す]   │
│                                             │
│ 文字起こし: [編集可能なナレーション本文]      │
│ 字幕確認:   [自動分割された字幕プレビュー]    │
└─────────────────────────────────────────────┘
```

## 操作フロー

1. スクリーンショットを読み込む
2. 画像解析を実行する
3. 画像の意味・注目箇所・前後関係を説明文として生成する
4. 利用者が説明文を確認・修正する
5. 「録音開始」を押してナレーションを吹き込む
6. 「停止」で音声ファイルを保存する
7. 音声を文字起こしする
8. 字幕単位へ分割する
9. 画像表示時間をナレーション音声の長さへ合わせる
10. 動画タイムラインへ追加する

## 画像解析の出力

画像解析結果は、最低限次の項目を持つ。

```json
{
  "summary": "この画面はGitHubのファイル更新結果を示している",
  "focus": [
    "更新されたファイル名",
    "コミット結果",
    "次に行う操作"
  ],
  "privacyWarnings": [
    "アカウント名が表示されている"
  ],
  "suggestedNarration": "ここではGitHub上のファイルを更新し、変更が反映されたことを確認しています。"
}
```

### 必須条件

- 解析結果はそのまま確定せず、必ず編集可能にする
- 個人情報、通知、メールアドレス、APIキー、非公開URLらしき表示を警告する
- 画像解析に失敗しても、利用者が手入力で続行できる
- 解析エンジンは交換可能にする

## ナレーション録音

### Webコンソール

スマホのブラウザからマイク利用を許可し、録音する。

生成例:

```text
projects/vlog-001/narration/
├── screenshot-001.webm
├── screenshot-002.webm
└── screenshot-003.webm
```

レンダリング前に、必要に応じてFFmpegでAACまたはWAVへ正規化する。

### 録音操作

- 録音開始
- 録音停止
- 再生確認
- 録り直し
- 音声削除

録音を開始する前に、対象スクリーンショットと説明文を同じ画面に表示する。

## 字幕生成

ナレーション音声ごとに個別に文字起こしする。

```text
screenshot-001.webm
  ↓
whisper/screenshot-001.json
  ↓
subtitles/screenshot-001.json
```

各字幕は、そのスクリーンショット場面の開始時刻を加算して、動画全体の時刻へ変換する。

例:

```text
オープニング終了: 42.0秒
スクリーンショット1の字幕: 0.0〜6.5秒

動画全体では: 42.0〜48.5秒
```

## スクリーンショット場面のレイアウト

標準レイアウト:

- 左側: スクリーンショット
- 右側: 画像解析から作った短い説明
- 下部: ナレーション字幕

```text
┌─────────────────────────────────────────────┐
│ ┌────────────────────────┐ ┌──────────────┐ │
│ │                        │ │ 何を示す画面か│ │
│ │   スクリーンショット    │ │ 注目点       │ │
│ │                        │ │ 結果         │ │
│ └────────────────────────┘ └──────────────┘ │
│           ナレーション字幕                   │
└─────────────────────────────────────────────┘
```

説明が長い場合は、動画へ全文を表示せず、要点だけを最大3項目に絞る。

## タイムライン形式

`vlog-plan.json` の画像項目を拡張する。

```json
{
  "type": "image",
  "source": "screenshots/03_screenshot.png",
  "role": "screenshot",
  "analysis": {
    "summary": "GitHubの更新結果",
    "focus": ["更新ファイル", "コミット結果"]
  },
  "narration": {
    "source": "narration/screenshot-001.webm",
    "transcript": "ここではGitHubの更新結果を確認しています。",
    "durationSeconds": 6.5
  },
  "layout": "image-with-side-explanation",
  "motion": "slow-pan"
}
```

ナレーションがない画像は、従来どおり固定秒数で表示できる。

## コンパイル処理

```text
素材読み込み
  ↓
画像解析
  ↓
説明文確認
  ↓
ナレーション録音
  ↓
個別文字起こし・字幕生成
  ↓
タイムライン時刻へ変換
  ↓
Remotion用データ生成
  ↓
プレビュー
  ↓
プライバシー確認
  ↓
動画書き出し
```

## MVP完成条件

- スマホのWeb画面でスクリーンショットを確認できる
- 説明文を表示・編集できる
- 録音開始・停止・再生・録り直しができる
- 録音音声から字幕を生成できる
- 音声の長さに合わせて画像表示時間が決まる
- 画像、横の解説、下の字幕を含む動画場面を書き出せる
- 画像解析が使えなくても手入力で完成できる

## MVPでは行わないこと

- 完全自動で説明を確定する
- 無確認で動画を公開する
- 高度な音声編集
- 多人数同時編集
- 複雑なタイムライン編集
- 自動YouTube投稿

## 実装順

1. Webコンソールの画像カードと並び替え
2. 説明文の手入力・保存
3. ブラウザ録音と音声保存
4. 個別音声の文字起こし・字幕生成
5. Remotionの左右分割レイアウト
6. 画像解析アダプター
7. プライバシー警告
8. 第1回Vlogでドッグフーディング
